# Projeto Lista Dinâmica

Este projeto implementa uma lista dinâmica (lista ligada duplamente encadeada) em Java, com uma interface de console para operações básicas.

## Funcionalidades

- Inserir elemento
- Inserir vários elementos em sequência
- Remover elemento
- Remover vários elementos em sequência
- Remover todas as ocorrências de um elemento
- Ordenar em ordem crescente
- Ordenar em ordem decrescente
- Limpar a lista
- Exibir a lista
- Obter primeiro elemento
- Obter último elemento

## Como executar

1. Certifique-se de ter o Java instalado (JDK 8 ou superior).
2. Navegue até o diretório `src`.
3. Compile os arquivos: `javac *.java`
4. Execute o programa: `java Main`

## Estrutura do Projeto

- `IListaDinamica.java`: Interface para a lista dinâmica.
- `INo.java`: Interface para o nó.
- `ListaDinamica.java`: Implementação da lista dinâmica.
- `No.java`: Implementação do nó.
- `Main.java`: Classe principal com o menu interativo.
